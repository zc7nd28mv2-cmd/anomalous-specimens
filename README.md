# 异常样本 / ANOMALOUS SPECIMENS

一份可被打开的异常数字档案。不是商店，不是商品页。

系统先启动。样本随后出现。001「仙桃梦」是一份可以连续阅读的完整档案。
故事结束后，现场记录 PD-001 才会作为残留数据被打开。

## 本地运行

```bash
npm install
npm run dev
```

打开 [http://127.0.0.1:43147](http://127.0.0.1:43147)。

第一屏是黑的，这是故意的。

右下角可以开关声音。没有背景音乐。

## 技术

- Next.js（App Router）
- TypeScript
- Tailwind CSS
- IBM Plex Mono / Noto Sans SC

没有登录。没有数据库。没有结算。
